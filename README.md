# P2P File Distribution System

## Overview

A peer-to-peer file distribution system inspired by BitTorrent.

The system allows multiple peers to exchange file pieces without
requiring a central server to transfer the actual file data.

## Objectives

- Implement a central tracker for peer discovery.
- Divide files into smaller pieces.
- Transfer file pieces between peers.
- Verify file integrity using SHA-256.
- Implement different piece-selection strategies.
- Measure download performance and peer contributions.

## Technologies

- Python
- Socket Programming
- Multithreading
- SHA-256
- Pandas
- Matplotlib
